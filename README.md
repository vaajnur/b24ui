# Учебное приложение Bitrix24 UI: сделки

Небольшой Vue + Vite проект для знакомства с Bitrix24 UI. По прямой ссылке он показывает демо-данные; внутри портала приложение инициализирует B24JsSDK и загружает сделки и компании. В форме сделки можно найти компанию через поисковый список. Создание сделки передаёт выбранный `companyId` в `crm.item.add`, связывая запись со справочником компаний CRM.

## Запуск на компьютере

```sh
npm install
npm run dev
```

Откройте URL, который напечатает Vite. Локальный режим использует только демонстрационные данные. Для проверки сборки используйте `npm run build`.

## Что сейчас подключено

- `@bitrix24/b24ui-nuxt` через официальный Vite-плагин для Vue;
- `@bitrix24/b24jssdk` и `initializeB24Frame()` для приложения внутри Bitrix24;
- `crm.item.list` для чтения сделок (тип сущности `2`) и компаний (тип сущности `4`);
- `crm.item.add` для создания сделки с привязкой через поле `companyId`.

Секреты и вебхуки в браузер не помещаются. SDK получает контекст авторизации текущего пользователя из iframe портала.

## Чтобы открыть приложение в облачном Bitrix24

Сначала соберите проект и упакуйте содержимое `dist/` в ZIP (в архиве `index.html` должен находиться в корне). Затем создайте локальное приложение типа **Static** и загрузите архив: Bitrix24 разместит его сам, отдельный HTTPS-хостинг не нужен. Для учебного варианта достаточно выдать приложению CRM-права на сделки. Не публикуйте архив или доступ к порталу с секретами.

В интерфейсе портала откройте **Ресурсы разработчика → Типовые сценарии → Другое → Локальное приложение**, выберите **Static** и загрузите архив. Название пункта меню можно указать, например, «Учебные сделки». В разделе настройки прав разрешите CRM-доступ к сделкам и компаниям. После обновления приложения загрузите новую сборку ZIP вместо предыдущей.

Если при первом запуске локальное приложение недоступно на тарифе или появляется ошибка прав, проверьте активность пробного тарифа и роль текущего пользователя. Список сделок ограничен правами пользователя и доступными REST-методами.
